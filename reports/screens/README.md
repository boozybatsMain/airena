# Кадры боёв

Сюда пишет вьюер в режиме съёмки: `?shots=1&n=12&oct=<тег>&gor=<тег>` — полные кадры
вместе с HUD, по одному на такт съёмки.

Самих кадров в репозитории нет: `.gitignore` отсекает `reports/screens/*.png`, потому что
это гигабайты одноразовой картинки, которую пересоздаёт одна команда. Каталог держится
этим файлом — README проекта ссылается на путь, и гейт `checkprompt` проверяет, что путь
существует в ТОМ, ЧТО ОТГРУЖЕНО, а не только в рабочем дереве.
