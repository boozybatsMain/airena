# Снимки визуальной проверки

Снято головой без рук: настоящий вьювер, настоящий цикл кадров, камера
поставлена вручную. Не украшение репозитория — свидетельство, к которому
привязаны утверждения в комментариях.

| файл | что доказывает |
|---|---|
| `a-readkit.png` | зона БЕЗ декорации: read-kit рисует кольцо на полу, и больше ничего |
| `a-ir.png` | та же зона С декорацией: восходящий купол искр поверх того же кольца. Разницу видно — то есть уровень 1 не «есть в коде», а виден |
| `b-cone-low2.png` | тот же конус с низкого ракурса. Снимок, на котором стало видно, что формы спрайтов не работают: штрих и осколок были одинаковыми пятнами |
| `c-shapes.png` | четыре формы рядом после починки: точка, штрих, осколок, искра. Различимы |
| `howto.png` | подсказка «как читать бой» на первом бою. Объяснение красного пятна, тонкой линии и белой оболочки существовало только в дев-вьювере и по-английски; игрок смотрел бой, не понимая, что видит |
| `e-decals2.png` | следы на полу тремя элементами после того, как цвет стал браться по контрасту к белому полу, а не по выбору автора |

Порядок снимков — это порядок работы: сначала проверили, что декорация вообще
видна, потом нашли на низком ракурсе, что две оси грамматики мертвы, потом
починили и пересняли. Гейт `tools/checkvfx.mjs` теперь держит обе находки, но
нашёл их глаз, а не гейт.
